## 2. Q1~Q5 逐题作答

### Q1 · carry 收益项（funding 年化 3%）纳入成本模型后，`cost_ok`（成本/毛利≤0.35）在 180d + 4h/1d 粒度下能否真正改善？结构性优势在什么条件下才成立？

**明确结论：能改善（方向对），但改善幅度有上限，且在 taker 费率下、4h 粒度下仍大概率不过线——carry 只能覆盖 4h 持仓段，覆盖不了 4h 信号段的 taker 成本。结构性优势成立的硬条件是「成本分子从 taker 翻转为 maker + 持仓段 ≥ 4h 使 carry 覆盖成本段」，二者缺一则 carry 只是账面分子变小、不是过线。**

**成本派视角的量化拆解（全部本人由盘上数字回读自算）：**

1. **carry 在 180d 窗口下是「年化摊薄后的小数项」，不是「每笔收益项」。**
   - funding 年化 3%（BTC，盘上 169d 窗口）= 8h 均值 +2.7e-05 × 3 × 365（§2.2）。
   - 4h 粒度持仓 1 bar（4h）：该 4h 段跨 0.5 个 8h 结算点 → carry ≈ 3% × (4/8760) ≈ **0.0137%**（年化×时点占比）；
   - 1d 粒度持仓 1 bar（1d）：该 1d 段跨 3 个 8h 结算点 → carry ≈ 3% × (24/8760) ≈ **0.082%**。
   - 对比 taker roundtrip **0.2%**（§2.1）：4h 段 carry 0.0137% 只覆盖 roundtrip 的 **~6.9%**；1d 段 carry 0.082% 只覆盖 **~41%**。**carry 即便全算进去，4h 粒度仍远不够把 0.2% roundtrip 抹平。**

2. **carry 把成本从扣项翻转为收益项的结构性方向，仅在「费率结构 + 持仓段」同时改造后才真正成立：**
   - **费率侧（成本分子，占单腿 71%，§2.1）**：taker 0.1%/边 是 carry 过线的第一障碍。若开仓/平仓改走 **maker**（VIP0 maker 0.1% 同价，需更低费率场所或 VIP>0 / GT 抵扣才能压分子）→ roundtrip 才能从 28bp 实质下降，carry 才有「空间」覆盖。**费率不降，carry 在 taker 口径下 4h 粒度无过线可能。**
   - **持仓段侧（carry 摊薄粒度）**：`carry_yield = funding_rate × position_direction × bars_held × (8h结算)`（§5.2）。`bars_held` 越长，单 bar 摊到的 carry 越高。4h 粒度（持仓常 1 bar）carry 摊薄最薄；1d 粒度（持仓跨 3 结算点）carry 摊薄最高。**因此 1d 比 4h 更有机会，但 1d 只有 180 根（§G-3），样本薄（见 Q2）。**

3. **「成本/毛利≤0.35」在 carry 改造后的真实含义（§5.2 公式）：**
   ```
   net_pnl = price_pnl + carry_yield - roundtrip_cost
   cost_ok = (roundtrip_cost - carry_yield) ≤ gross_pnl × 0.35
   ```
   carry 把 `roundtrip_cost` 这一侧从「纯扣项」变成「`roundtrip_cost - carry_yield` 净额项」——**方向对**（分子变小甚至可转负）。但**达标线分母 `gross_pnl` 也须按 0.5x 抢跑折扣复算**（§5.2 C 专家加严），且 `roundtrip_cost` 须含 1~3s 时延。**只翻转 carry 一侧、不动费率分子与抢跑分母，0.35 仍大概率不过（4h 粒度）。**

4. **成立条件汇总（硬前置）：**
   - 费率侧：开/平仓走 maker 或更低费率场所，使单腿成本 < 14bp（现状 10bp 费 + 4bp 滑）；
   - 持仓段：≥4h 粒度（1d 优先），使单 bar carry 摊薄 ≥ 0.08%；
   - 分母侧：gross_pnl 按 0.5x 抢跑折扣 + 1~3s 时延折算后复算；
   - 样本侧：4h=1080 根须 ≥30 笔成交且覆盖 ≥1 个完整 carry 持仓周期（1d=180 根样本薄，见 Q2）。
   - **以上任一不满足，carry 改造只是账面分子变小，不能宣布「cost_ok 真正改善」。**

### Q4 · 若选 ① G1 carry，成本口径硬前置（含 1~3s 时延 + 0.5x 抢跑折扣 + ≤0.35 复算）的具体复算公式是什么？哪些组在成本口径下会被直接判负？

**一、具体复算公式（C 专家加严口径，基于 §5.2 + §2.1 + §2.3）：**

```
# 单条 bar 的成本项（计入 1~3s 成交时延 + 0.5x 抢跑折扣）
per_bar_cost = (taker_fee × 2 + slippage × 2 + latency_drift_1_3s) × 0.5   # 抢跑折扣打在毛利侧，cost 侧计时延
# 实际采用：分母按 0.5x 抢跑折扣，cost 侧记 1~3s 时延折算的不利价格漂移
gross_pnl_disc   = 0.5 × gross_pnl_original                    # 0.5x 抢跑折扣（§5.2 C 专家加严）
roundtrip_cost   = taker_fee × 2 + slippage × 2 + latency_1_3s  # 28bp 基础 + 1~3s 时延折算
carry_yield      = funding_rate × position_dir × bars_held × (8h结算)  # §5.2
net_cost         = roundtrip_cost - carry_yield                # carry 把 cost 翻转为净额
cost_ok          = net_cost ≤ 0.35 × gross_pnl_disc             # 达标线 ≤0.35（不放宽、不设过渡档）

# 等价式（§5.2 原式 + C 专家加严项）
cost_ok = (roundtrip_cost - carry_yield) ≤ 0.35 × (0.5 × gross_pnl)
```

- **1~3s 时延**：信号→成交 1~3s，折算为 bar 内不利价格漂移，计入 `roundtrip_cost`（§2.3「未计 1~3s 成交时延」为本轮须补项）。
- **0.5x 抢跑折扣**：做市商抢跑使毛利先打 0.5 折，分母 `gross_pnl` → `0.5 × gross_pnl`（§5.2「毛利先按做市商抢跑打 0.5 折」）。
- **carry 翻转**：`roundtrip_cost - carry_yield`，carry 为收益项（§5.2 改造）。
- **taker 费率**：0.1%/边 = roundtrip 0.2%（VIP0 官方事实，§2.1）；滑点 4bp/边（保守假设，实测 $500 量级 <1bp，§2.2）。
- **达标线**：`cost_ok` 按「成本/毛利 ≤ 0.35」复算，**0.35 不放宽、不设过渡档**。

**二、哪些组在成本口径下会被直接判负（按 L13「实际成交打几折」逐条判负，非脑补）：**

1. **taker 费率下、4h 粒度、任意币对 → 直接判负。**
   - 依据 Q1 量化拆解：4h 段 carry ≈ 0.0137%，只覆盖 roundtrip 0.2% 的 ~6.9%；`net_cost = 0.2% - 0.0137% ≈ 0.186%`，而 `0.35 × (0.5 × gross_pnl)` 在 4h 薄毛利下远小于 0.186% → **不过 0.35**。
   - **结论：taker + 4h = 必然判负**（除非费率侧先改 maker，使 roundtrip < 0.05%）。

2. **BCH（负 carry -10.7%，§2.2）做多方向 → 直接判负。**
   - carry_yield 为负（`funding_rate` 负 × 多方位向 = 负收益项），`net_cost = roundtrip_cost - carry_yield = 0.2% - (-10.7%年化摊薄)` 更大 → **carry 反向放大成本，必负**。
   - （BCH 不在做多 carry 名单 §六.3，做空方向 funding 收入为负，§二「方向错误」。）

3. **SOL / XRP / AVAX / ADA（负 carry，§2.2）做多方向 → 直接判负。**
   - 负 carry（SOL -1.8% / XRP -0.9% / AVAX -0.9% / ADA≈0）× 多方位向 → carry_yield ≤ 0，`net_cost` 不减反增 → **做多 carry 方向不成立**（§二「做空永续 + 持现货的多头 carry 方向收益为负」）。
   - **故做多 carry 仅限 BTC/ETH/DOGE/LTC（正 carry，§六.3）**，SOL/XRP/AVAX/ADA 做多组直接判负。

4. **1d 粒度 + 成交 <30 笔 → 判负（样本薄，不计通过）。**
   - 1d=180 根（§G-3），若成交 <30 笔（对照本人 F-1「12 组 cost_ok 全 <30 笔判薄样本」口径）→ 样本不足，**cost_ok 即便账面 True 也不计通过**（L13：薄样本答不出「实际成交打几折」）。

5. **含 `N/A(180d限制)` / `extreme_pnl=0` 占位的组 → 判负（不当通过）。**
   - 极端段(2026-02) funding 不存在（§六.1），任何含该段占位的组 `extreme_pnl` 不可评估 → **标 N/A、不计通过、不放宽**。

**三、唯一可能过线的组（方向判断，须费率侧先改）：**
- **BTC/ETH/DOGE/LTC + 1d 粒度 + 成交≥30笔 + 费率改 maker（roundtrip <0.05%）+ 1~3s 时延 + 0.5x 抢跑** → `net_cost` 才有可能 < `0.35 × 0.5 × gross_pnl`。**这是 ① 唯一有希望的子集，其余组在成本口径下直接判负。**
