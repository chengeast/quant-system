## 1. 官方费率（可验证事实）

- 来源：Gate.io 现货费率页（Spot Fee Rate），VIP0 现货 Maker/Taker = **0.1% / 0.1%**；GT 抵扣费率 0.09%/0.09%；VIP1–16 随 30D 成交量与 GT 持仓逐级下降。
- 项目 `config/strategy_params.yaml:103` 的 `taker_fee_pct: 0.001` 与官方 VIP0 现货 taker 一致——**这是交易所事实，不是拍脑袋**。
- 说明：账号实际费率档（是否 VIP>0、是否用 GT 抵扣）会低于 0.1%。`GET /spot/fee` 可查本人真实档，但需该 API key 具备对应读权限（本 key 返回 401 签名不匹配 / 权限受限，本轮未强行拉取，不影响 0.1% 作为保守上界成立）。

## 2. 滑点：假设 vs 实测

### 2.1 假设（现状，未实测定量）

`PaperBroker`（`execution_manager.py`）与 `BacktestConfig`（`engine.py`）固定用 `slippage_bps=4.0`，落在冻结区间 [3,5]。M8 成本口径：单腿 `cost_rate = 0.1% + 4bp = 0.14%`，两腿开仓 + 两腿平仓 → 一次完整 roundtrip = **28bp**（见 `strategy_feasibility_probe.py` 的 `COST_BP=28.0`）。

### 2.2 本次实测（实拉 Gate.io `/spot/order_book`）

项目仓位规模：`leg_equity_pct=0.05 × base_equity=$10000 = 每腿 $500` 名义。按 taker 不利方向吃订单簿：

| 币对 | mid | 名义 | 吃穿档数 | 冲击滑点(buy) | 冲击滑点(sell) | 点差(首档) |
|------|-----|------|---------|--------------|---------------|-----------|
| ETH_USDT | 2238.40 | $500 | 1 | **0.022 bp** | 0.022 bp | 0.045 bp |
| SOL_USDT | 89.50 | $500 | 1 | **0.559 bp** | 0.559 bp | 1.119 bp |

- 深度（累计到 10bp）：ETH 卖侧 65.97 / 买侧 53.33 ETH；SOL 卖侧 441.9 / 买侧 4197 币——对 $500 量级极充裕，**只需吃 1 档**。
- 结论：$500 量级 taker 的**真实盘口冲击滑点 < 1bp**，远小于模型假设的 4bp。

### 2.3 敏感性（关键）

成本口径里滑点 4bp 仅占总成本的一小部分：

- 单腿成本 14bp = 10bp 手续费 + 4bp 滑点；手续费占 71%，滑点占 29%。
- 即便把滑点从 4bp 打到 0bp（极限乐观），单腿 14bp → 10bp，roundtrip 28bp → 20bp，**总成本只降 1/7 ≈ 14%**。
- M8 实测累计毛利 $107.93 vs 成本 $192.54（成本/毛利 1.784）。滑点清零后成本约 $165，成本/毛利 1.53，**仍远超 0.35 冻结门槛**，仍不通过。

> 即：**滑点假设即便偏保守，也不是 M8 不达标的主因**；主因是 0.1% taker 手续费本身（占成本 71%）+ 1h 配对均值回归单笔毛利太薄。

## 3. 对既往结论的影响

- 不改变第六轮「1h + 加密现货 + 比例成本 + 冻结门槛」切片下无相似策略通过的结论：成本分子即便砍掉全部滑点，成本/毛利仍 >0.35。
- 不改变第三轮 3:0 关闭 1h 统计套利上线分支的裁决。
- 唯一新增可执行事实：`taker 0.1%` 是 Gate.io VIP0 官方费率，若账号实际是 VIP>0 或用 GT 抵扣（0.09% 或更低），手续费可再降，**但降幅不足以翻盘**（需整体成本降到 10.6bp 毛利的 35% 以内，即 roundtrip < ~3.7bp，而手续费一项就已 10–20bp）。

## 4. 边界与禁令

- 本次为**只读**盘口与公开费率核实，未修改 `config/strategy_params.yaml` 冻结参数，未启用实盘，未删 M3/M4 骨架。
- 滑点实测是**单一时点**盘口，非 410 天逐 bar 的历史深度回放；历史极端时刻（如 2026-02 崩盘）盘口会稀薄、滑点放大，4bp 作为保守上界仍合理。
- `GET /spot/fee` 拉本人真实费率档因 API key 权限未成功，0.1% 仍按官方 VIP0 保守值使用，不放宽。
