## 5. G-3 硬前置（C 专家 Q4 成本口径，老板 2026-11-10 已拍板）

```
# 成本口径（C 专家加严，含 1~3s 时延 + 0.5x 抢跑折扣）
roundtrip_cost   = taker_fee × 2 + slippage × 2 + latency_1_3s
carry_yield      = funding_rate × position_dir × bars_held × (8h结算)
net_cost         = roundtrip_cost - carry_yield
cost_ok          = net_cost ≤ 0.35 × (0.5 × gross_pnl)
# 0.35 不放宽、不设过渡档
```

**直接判负组（C 专家 Q4）：**
1. taker + 4h 粒度（4h 段 carry 仅覆盖 roundtrip ~6.9%）→ 必判负
2. BCH 做多（负 carry -10.7%，carry_yield < 0）→ 必判负
3. SOL/XRP/AVAX/ADA 做多（负 carry）→ 必判负
4. 1d 粒度 + 成交 <30 笔（薄样本）→ 判负
5. 含 N/A(180d限制) 占位的组 → 判负

**唯一可能过线的子集：** BTC/ETH/DOGE/LTC + 1d 粒度 + 成交≥30 笔 + maker 费率（roundtrip <0.05%）+ 1~3s 时延 + 0.5x 抢跑折扣
