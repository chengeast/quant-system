# 阶段 2 补充 · 金融专家 3 人辩论裁决（少数服从多数）

> 参与：A 均值回归派 / B 风险派 / C 高频因子派
> 规则：每个争议点按多数决；少数派保留意见；裁决为阶段 3/4 的执行参数基准。
> 前置：3 位专家已确认"统计套利在 Gate.io 单所有有限 alpha，是后续做市/订单流的地基"（C 的 alpha 来源分析已并入本结论）。

## 裁决结果（逐点）

### 争议点 1：币种对筛选阈值
| 专家 | 立场 |
|----|------|
| A | corr≥0.7 初筛 + EG + Johansen 校验 |
| B | corr≥0.8 + EG p<0.01 + 半衰期 20–40 bars |
| C | corr≥0.85 + 流动性过滤（价差≤5bp、日成交≥$50M）+ 半衰期 25–50 bars |

**裁决（3:0 一致，取最严）**：
- 相关性初筛：**corr ≥ 0.85**（B、C 主张收紧，A 的 0.7 被否）
- 协整：**Engle-Granger 为主 + Johansen 交叉校验**（A 保留，双校验防伪回归）
- 流动性硬过滤：**日成交额 ≥ $50M**、盘口价差 ≤ 5bp（C 独有，B/A 未反对 → 采纳）
- 半衰期：**25–50 bars（5m）**（B 的 20–40 与 C 的 25–50 取交集）

### 争议点 2：进场 / 离场 / 超时
| 专家 | 进场 | 离场 | 超时 | 止损 |
|----|----|----|------|------|
| A | ±2.5σ | 0.5σ | max(4h,3H) | 无 |
| B | ±3σ | 0.5σ | max(2h,2H) | 单腿 1.5σ |
| C | ±3σ | 0.5σ | max(3h,1.2H) | 单腿 2σ |

**裁决（2:1，B 与 C 一致胜出）**：
- 进场：**±3σ**（A 的 2.5σ 落选，B/C 认为 2.5σ 假收敛打脸太频）
- 离场：**0.5σ**（3 方一致）
- 超时强平：**max(3h, 1.2H)**（C 值胜出；A 的 4h 太宽、B 的 2h 太紧）
- 止损：**单腿 2σ 硬止损**（C 值；B 的 1.5σ 过紧、A 不设止损被否）

### 争议点 3：对冲比率 h
| 专家 | 窗口 | 约束范围 | 日变化率 | 重估 |
|----|----|---------|---------|------|
| A | 60 bar | [0.5,2.0] | <10% | 逐 bar |
| B | 40 bar | [0.5,1.5] | <5% | 每周 |
| C | 48–72 bar | [0.5,2.0] | 10% | 慢变可接受 |

**裁决（2:1，A 与 C 一致胜出，B 的"每周重估"落选）**：
- 窗口：**60 bar（5m）** 收益率 OLS（取 A 值；B 的 40 bar 被认为反应过慢）
- 约束范围：**h ∈ [0.5, 2.0]**（A/C 一致；B 主张收紧到 1.5 落选，但保留告警：h 接近 2.0 时降杠杆）
- 日变化率：**< 10%**（A/C 值；B 的 5% 过严落选）
- **附加风控（吸纳 B 意见）**：h 越出 [0.5,2.0] 即整对 INVALID + 告警；h 日变化率触 10% 即暂停该对

### 争议点 4：回测通过门槛
| 专家 | 回撤 | 夏普 | Calmar | 其他 |
|----|----|----|----|------|
| A | ≤10% | ≥2.0 | ≥1.5 | 含 2024-09 极端段 |
| B | ≤8% | ≥2.5 | ≥2.0 | 连亏≤5 笔 |
| C | ≤10% | ≥2.0 | ≥1.5 | 滑点≥3–5bp/边，成本≤毛利 35% |

**裁决（2:1，A 与 C 一致胜出）**：
- 回撤：**≤10%**
- 夏普：**≥ 2.0**（B 的 2.5 落选，C 论证成本假设下 2.5 不可达）
- Calmar：**≥1.5**
- **成本可执行性（吸纳 B、C 意见，升级为硬门槛）**：滑点 ≥ 3–5bp/边、每笔成本 ≤ 毛利 35%
- 极端段：必须含 2024-09 事件段不亏（A）+ 最长连续亏损 ≤ 5 笔（B，作为附加项采纳）

## 少数派保留意见
- **B（风险派）**：保留对"回撤 10% 在 crypto 双币种敞口下偏松、夏普 2.0 未逼出真 alpha"的异议，主张实际执行中以回撤 8% 为内部预警线。
- **A（均值回归派）**：保留对"±3σ 进场过于保守、机会变少"的异议，主张实盘阶段用样本外数据复核 3σ 是否导致信号过稀。
