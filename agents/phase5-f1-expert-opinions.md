## 3. 逐题作答（Q1~Q5）

### Q1 · 0.499 → 0.5550 → 1.2093 且首次出现 12 组 `cost_ok=True`：实质改善还是小样本 / 降频假象？

**结论：不是实质改善，是「降频 + 小样本 + 假稳」三重叠加的统计假象；且因缺协整真实性基础，任何夏普数值都不构成 alpha 证据。**

依据（数字均 `json.load` 回读）：

1. **夏普与成交笔数单调反向**：`0.49883 / 82 笔`（`pair_param_sweep.json`，75 组）→ `0.5550 / 76 笔`（`ltc_avax_finescan.json`）→ `1.2093 / 4 笔`（`pair_param_sweep_avax_ada.json`，125 组）。夏普抬升伴随笔数塌缩，是「少交易几笔、波动被平滑、噪声被当 alpha」的典型特征，非单笔 alpha 变强。
2. **Top1 小样本到不可统计**：`1.2093` = ETH/AVAX · 1d · 3.5/2.5/2.0，**仅 4 笔、901 根 bar**，净 +1.58%、Calmar 2.1878、回撤 0.29%、`cost_ok=True` 但 `gate6_pass=False`（`pair_param_sweep_avax_ada.json` 回读）。4 笔交易的夏普标准误极大；Calmar 2.1878 建立在「几乎未经历回撤」之上，不可置信。**1d 仅 901 根 bar**（`bars` 字段 25 组全为 901）。
3. **12 组 `cost_ok` 是降频的被动达标，不是成本改善**：回读 12 组 `cost_ok=True` 的 `tf` 分布 = **{'1d': 12}**、成交 **4~23 笔**；周期均值表（`pair_param_sweep_avax_ada.md` §7）显示 1d 平均 14.9 笔 / 成本 $83.45，而 1h 平均 146.0 笔 / $402.10。`agents/phase6-similar-strategy-probe.md` §0 已证成本/毛利与仓位、换手、K 线尺度、调参全部无关（比例费率分子分母同比例缩放）；`agents/phase7-cost-provenance.md` 已证主因是 taker 0.1% 费率而非滑点。故 12 组 `cost_ok` 属「少交易 + 单笔空间大」的账面覆盖，非结构改善。

## 3. Q1~Q5 逐题作答

### Q1 · 0.499 → 0.5550 → 1.2093、首次 12 组 `cost_ok=True`：实质改善还是小样本 / 降频假象？

**明确结论：不是实质改善，是「降频 + 小样本」共同制造的统计假象；且「最坏情况在 4 笔样本里根本不可能被观测到」；50 组 N/A 与 25 组 `extreme_pnl=0` 占位均不构成真实穿越检验。按 L13「最坏情况怎么办」，这组数字连被讨论为「改善」的资格都不具备。**

**依据与数据（出处见 §2）：**

1. **夏普抬升与成交笔数单调反向，是降频签名而非 alpha 变强**：0.499 / 82 笔 → 0.5550 / 76 笔 → 1.2093 / **4 笔**（三套 JSON 逐组回读；`phase5-p8-next-direction.md` §0.3 补充取证行）。C-2b §7 周期均值显示 `cost_ok` 只出现在 1d（平均 **14.9 笔**、平均成本 **$83.45**），而 1h 平均 **146.0 笔 / $402.10**、15m **120.8 笔 / $348.21** 全部 `cost_ok=0`（`pair_param_sweep_avax_ada.md` §7）。**12 组 `cost_ok=True` 全在 1d、成交 4~23 笔**（本人 `json.load`：`{'1d': 12}`、min 4 / max 23）。结论：`cost_ok` 是「少交易让毛利覆盖成本」得来的，**不是成本模型改善**——这与 `agents/phase7-cost-provenance.md` §2.3「taker 0.1% 占成本 71%、滑点清零成本仅降 14%、成本/毛利仍 1.53」的结构判断一致。降频只能把分母（成本笔数）压小，不能把单笔毛利做大 5.1 倍（`phase6-similar-strategy-probe.md` §0）。

2. **数值仍全面不达标，连「接近」都谈不上**：125 组 `passed` 0 / `gate6_pass` 0 / 夏普≥2.0 **0** 组（本人 `json.load`）；最高夏普 1.2093 距门槛 2.0 差 **0.7907**；逐项门槛 `cal` 仅 2 组、`sh` 0 组（`gate6_detail` 回读）。Top1 `gate6_pass=False`（`pair_param_sweep_avax_ada.md` §3）。**冻结 6 条一律不放宽**，故无「带病申报改善」的空间。

3. **重点回答「最坏情况在 4 笔样本里能否被观测到」——不能，这是本人最核心的否决理由**：
   - L7 的尾部风险是**稀有事件**：协整断裂 / 黑天鹅 / 价差永久发散，发生的频率低、单次损失大。4 笔成交、901 根 1d bar，统计上**没有左尾样本**；夏普 1.2093、Calmar 2.1878、回撤 0.29% 全部由一个极小分母和「未走出不利路径」算出，**只要多一笔亏损或一次跳空穿过软止损，三个数全部崩塌**。这不是稳健性，是「没被抽到坏样本」。
   - 更直接：Top1 的 `extreme_pnl = 0.000973`（≈ **+0.097%**，`pair_param_sweep_avax_ada.json` Top1 字段直读）——所谓「2026-02 极端段不亏」实际只是约 10bp 的微小正数／近似无交易，量级上等于噪声，**完全不具备「穿越一次崩盘」的证据力**。用 4 笔样本去宣称「极端段不亏」，正是 L13 要拦下的「最坏情况怎么办」被跳过。
   - L8 补刀：1d 持有期跨越数月，regime change（趋势/震荡切换）暴露时间远长于 1h；静态 h 在长窗口里系统性失效的概率更高，`corr_monitor_60bar_summary.md` 显示 36 对滚动 corr 跌破 0.70 合计 **3135 次**、连最稳的 BTC/ETH 也有 **54 次**。**样本越少、持有越长 → 尾部越不可观测、漂移越致命**。这就是「最坏情况」在 4 笔里不可观测、却会在实盘里主导结果的机理。

4. **50 组 N/A 与 25 组 `extreme_pnl=0` 占位不构成真实穿越检验**：
   - 50 组（15m 25 + 30m 25）数据窗口不含 2026-02 → `extreme_evaluable=False`、`N/A（不可评估）`，`gate6_pass` 全 False、不计通过（本人 `json.load`；`pair_param_sweep_avax_ada.md` §1、§5、§130 行如实标注）。**「不可评估」不等于「通过」，更不等于「已检验」**。
   - 25 组（1h 4 / 4h 16 / 1d 5）虽窗口含 2026-02，但 `extreme_pnl==0.0` 是**引擎占位值**（该段无交易 / 净值持平），`extreme_survived=True` 属引擎既有口径；`phase5-p7-final-summary.md` §4.3 D7 与 `pair_param_sweep_avax_ada.md` §9 风险②均明确「不改引擎、不脑补为『真实穿越检验通过』」。
   - 本人逐组自算：**「可评估 ∧ survived ∧ extreme_pnl≠0」（真正有交易穿越且不亏）仅 21 组 / 125**；`extreme_survived=True` 原始 96 组里，50 组是 N/A 占位、25 组是 `extreme_pnl=0` 占位，**只有 21 组是真实观察**。也就是说 125 组里 **75 组（60%）根本没有构成穿越检验**，而报表上 `ext` 一项却记 46 组通过——**46 = 21 真 + 25 占位**，被占位值灌了水。

**Q1 落点（L13）**：把「最坏情况」摆上来——协整断裂、价差永久发散、无硬止损、4 笔样本、极端段靠占位——这套组合在回测里看不见，在实盘里会一次性亏掉前面所有「赚小钱」。故 1.2093 与 12 组 `cost_ok` 不能作为「实质改善」的证据；**它们恰恰证明了继续沿「降频找夏普」走会把策略推到无法证伪、也无法风控的角落**。

### Q4 · 是否必须先解决成本模型再谈策略迭代？风控视角判断 + 必须先落地的风控硬前置

### Q4 · 是否必须先解决成本模型，再谈任何策略迭代？
