1. **公开可查证**：逐因子给「来源（URL / 经典文献 / 公开实现）+ 逐字可量化定义 + 计算所需字段(OHLCV) + 买卖规则」。**来源拉不到标「未核实」，不编 URL、不脑补论文结论**（§2、§7）。
2. **① 可量化**：全部写成公式或可判定条件，无「酌情 / 视情况」。
3. **② 无未来函数**：**所有指标只用截至 bar t 及之前的数据**；滚动窗口一律 `rolling(N)` 于 t 收盘取值；通道类用 `shift(1)` 的**前 N 日**高低点（知乎 / CSDN 海龟源码均用 `highest[-1]` / `rolling().max().shift(1)` 防「当根最高价突破当根最高价」自我指涉）。**信号在 bar t 收盘计算，成交在 bar t+1 的 open**（防未来函数，同 I-1 R4）。
4. **③ 纯多头**：信号 = 「进场持有 / 出场空仓」二态；**任何因子的原始形态若含做空 / 反手空 / 对冲腿，本批一律剔除该腿，只保留多头侧**（海龟、Dual Thrust、R-Breaker 原版均含空头腿，§3 逐因子写明剔除处与为何仍可执行）。
5. **④ 满足 T+1**：`MIN_HOLD_BARS=1`，成交层拒绝同 bar 开平；逐笔 `exit_date > entry_date`、`exit_bar > entry_bar`；t 收盘出信号 → **t+1 open 成交**（买入与卖出同理）；**不用日内 OHLC 臆造同日反向成交**。
6. **统一参数、不铺大网格、不参数寻优、不过拟合搜索**（老板 17:37「别浪费时间」）：每因子**固定 1 组公开经典参数**（见 §3），全因子统一 1d 日线、统一标的池、统一成本、统一 28 年窗口、统一门槛。**因子数 15 个（在「建议 8~15」内）**；另有 3 项「仅收录、不单列回测」（换手率字段不足 / 格兰维尔同族重复 / 成交量均线·布林带宽·ATR 已并入），见 §3.4。

## §3 逐因子逐字可量化定义 + 字段 + 买卖规则（15 个）

**统一记号**（bar t = 第 t 根日线）：`O_t/H_t/L_t/C_t/V_t` = 开/高/低/收/成交量；`MA_n(C)_t = mean(C_{t−n+1..t})`；`RMA_n(x)` = Wilder 平滑 `x_t = (x_{t−1}·(n−1)+v_t)/n`；`shift1` = 前 N 日（`rolling(N).max().shift(1)`）；所有指标**只用到 ≤ t 的数据**。

**统一成交时序（防未来函数 + T+1）**：bar t 收盘算出 `sig_t ∈ {BUY, SELL, HOLD}`；`pending` 挂到 **bar t+1 的 `O_{t+1}` 成交**：空仓遇 BUY → 买入（`entry_bar=t+1`）；持仓遇 SELL → 卖出平仓（`exit_bar=t+2` 或更晚）。**逐笔 `exit_bar > entry_bar`、`exit_date > entry_date`、同 bar 开平被成交层拒绝（违反则该组 FAIL）**。「买入 → 持有 → 卖出平仓 → 空仓等待」，无任何空头腿。

**纯多头总说明**：以下每个因子的 SELL 一律解释为「**卖出平多、转为空仓等待**」，**不是开空**；原版含做空/反手/对冲的因子（F05 海龟、F14 Dual Thrust、F15 R-Breaker）在对应条目写明被剔除的腿。

### §3.1 趋势 / 均线（4 个）

**F01 MA 金叉死叉（MA5 / MA20）**
- 定义：`MA5_t=MA_5(C)_t`，`MA20_t=MA_20(C)_t`。
- 字段：`close`。
- 进场：`MA5_{t−1} ≤ MA20_{t−1}` 且 `MA5_t > MA20_t`（金叉，t 收盘确认）。
- 出场：`MA5_{t−1} ≥ MA20_{t−1}` 且 `MA5_t < MA20_t`（死叉）。
- 纯多头：金叉买入持有、死叉卖出空仓；无做空腿。来源 Murphy (1999)。

**F02 MACD（12, 26, 9）**
- 定义：`EMA12_t / EMA26_t` = C 的 12/26 日指数均线；`DIF_t = EMA12_t − EMA26_t`；`DEA_t = EMA9(DIF)_t`；`MACD柱_t = 2·(DIF_t − DEA_t)`（柱仅记录，不参与判定）。
- 字段：`close`。
- 进场：`DIF_{t−1} ≤ DEA_{t−1}` 且 `DIF_t > DEA_t`（DIF 上穿 DEA）。
- 出场：`DIF_{t−1} ≥ DEA_{t−1}` 且 `DIF_t < DEA_t`（DIF 下穿 DEA）。
- 纯多头：金叉持有、死叉空仓；无做空腿。来源 Appel (1979)。

**F03 DMI / ADX（14）**
- 定义：`TR_t = max(H_t−L_t, |H_t−C_{t−1}|, |L_t−C_{t−1}|)`；`+DM_t = H_t−H_{t−1}` 若 `(H_t−H_{t−1}) > (L_{t−1}−L_t)` 且 >0，否则 0；`−DM_t` 对称；`ATR_t = RMA_14(TR)`；`+DI_t = 100·RMA_14(+DM)/ATR_t`；`−DI_t = 100·RMA_14(−DM)/ATR_t`；`DX_t = 100·|+DI_t−−DI_t|/(+DI_t+−DI_t)`；`ADX_t = RMA_14(DX)`。
- 字段：`high, low, close`。
- 进场：`+DI_{t−1} ≤ −DI_{t−1}` 且 `+DI_t > −DI_t` 且 `ADX_t ≥ 20`（多方上穿 + 趋势成立）。
- 出场：`−DI_{t−1} ≤ +DI_{t−1}` 且 `−DI_t > +DI_t`（空方占优）**或** `ADX_t < 20`（趋势转弱）。
- 纯多头：**只在多方占优且趋势成立时持有**；转空方或趋势转弱即**空仓**，**不反手做空**（原 DMI 可双向，本批剔除空头侧）。来源 Wilder 1978（WebFetch 核验）。

**F04 动量 ROC（12）**
- 定义：`ROC_t = (C_t / C_{t−12} − 1) × 100`。
- 字段：`close`。
- 进场：`ROC_{t−1} ≤ 0` 且 `ROC_t > 0`（12 日动量由负转正）。
- 出场：`ROC_{t−1} ≥ 0` 且 `ROC_t < 0`（由正转负）。
- 纯多头：动量为正持有、为负空仓。来源 Wilder 1978 MOM / 公开 ROC 通用定义。

### §3.2 通道 / 波动率 · 经典公开策略（4 个）

**F05 唐奇安 / 海龟通道（20）**
- 定义：`U_t = max(H_{t−20..t−1})`（前 20 日最高，`rolling(20).max().shift(1)`）；`D_t = min(L_{t−20..t−1})`（前 20 日最低，`rolling(20).min().shift(1)`）。
- 字段：`high, low, close`。
- 进场：`C_t > U_t`（收盘上破前 20 日高）。
- 出场：`C_t < D_t`（收盘跌破前 20 日低）。
- 纯多头：**§3 定义已核验**（CSDN 海龟 `shift(1)` 前 N 日高 + 知乎 `highest[-1]` 防自我指涉）；**原海龟含「跌破 N 日低做空 / 反手」腿 → 本批严格剔除**，只保留「突破买入持有 → 跌破卖出空仓」多头侧；原 10 日出场 / 2N 止损 / 加仓 / 波动率仓位管理本批**不模拟**（统一参数、不铺网格，如实标注为简化日线近似）。来源 CSDN + 知乎（WebFetch 核验）。

**F06 布林带（20, ±2σ）含带宽**
- 定义：`MID_t = MA_20(C)_t`；`σ_t = std(C_{t−19..t}, ddof=0)`；`UP_t = MID_t + 2σ_t`；`DN_t = MID_t − 2σ_t`；**布林带宽 `BW_t = (UP_t − DN_t)/MID_t`**（逐字给出，覆盖「带宽」要求；本批只记录 BW、不据 BW 单独寻优或另立因子）。
- 字段：`close`（带宽另需 MID，同源）。
- 进场：`C_t > UP_t`（收盘上破上轨）。
- 出场：`C_t < MID_t`（收盘跌破中轨）。
- 纯多头：上破上轨买入持有、跌破中轨卖出空仓；**不做「下破下轨做空 / 均值回归反手」**。来源 Bollinger (2001) + Britannica（WebSearch 命中）。

**F07 ATR 通道（ATR14, k=1.5, MA20）**
- 定义：`TR_t` 同 F03；`ATR_t = RMA_14(TR)`；`MID_t = MA_20(C)_t`；`UP_t = MID_t + 1.5·ATR_t`。
- 字段：`high, low, close`。
- 进场：`C_{t−1} ≤ UP_{t−1}` 且 `C_t > UP_t`（收盘上穿上轨）。
- 出场：`C_t < MID_t`。
- 纯多头：上穿买入持有、跌破中轨空仓；**不做下轨做空**。ATR 来源 Wilder 1978（WebFetch 核验）；通道组合为本批公开定义转述。

**F14 Dual Thrust（N=4, k1=k2=0.5）· 日线近似**
- 定义（前 N 日，全部 `shift1`）：`HH=max(H_{t−N..t−1})`，`LC=min(C_{t−N..t−1})`，`HC=max(C_{t−N..t−1})`，`LL=min(L_{t−N..t−1})`；`Range_t = max(HH−LC, HC−LL)`；**锚 = 当日 `O_t`**（t 收盘时已知，无未来函数）；`U_t = O_t + 0.5·Range_t`；`D_t = O_t − 0.5·Range_t`。
- 字段：`open, high, low, close`。
- 进场：`C_t > U_t`（t 收盘突破上轨 → t+1 open 买入）。
- 出场：`C_t < D_t`（t 收盘跌破下轨 → t+1 open 卖出平多）。
- 纯多头 + 日线近似如实标注：原版为**日内**「开盘价锚定、盘中触及即入场、方向反转直接反手、14:55 强平隔夜清零」；本批**① 不模拟日内盘中触发/强平，改为 t 收盘判突破 + t+1 open 成交（防未来函数、满足 T+1）；② 严格剔除「反手开空」腿，下破只平多转空仓**。Range/上下轨公式来源知乎（WebFetch 核验）。

**F15 R-Breaker（前一日 H/L/C 七价位）· 日线近似**
- 定义（用 `t−1` 日数据，无未来函数）：`pivot_t = (H_{t−1}+L_{t−1}+C_{t−1})/3`；`R_t = H_{t−1}−L_{t−1}`；`r3_t = pivot_t + 1.0·R_t`；`r1_t = pivot_t + 0.5·R_t`；`s1_t = pivot_t − 0.5·R_t`；`s3_t = pivot_t − 1.0·R_t`（pivot/r1/r3/s1/s3 五个价位，知乎正文；原文另有「六级价位」表述但只列 5 个公式，本批**不补写第 6 个**）。
- 字段：`high, low, close`（用前一日值 + 当日收盘）。
- 进场（趋势模式·纯多头）：空仓时 `C_t > r3_t`（收盘突破 r3 → t+1 open 买入）。
- 出场（反转模式·纯多头）：持仓时 `C_t < r1_t`（回落跌破 r1 → 平多空仓）。
- 纯多头 + 日线近似如实标注：原版**趋势模式含「跌破 S3 追空」、反转模式「平多并反手开空」→ 本批严格剔除全部做空/反手腿**，只保留「突破 r3 买入持有 → 跌破 r1 平多空仓」；不模拟日内强平。公式来源知乎（WebFetch 核验）。

### §3.3 超买超卖反转（4 个）

> 反转类因子的纯多头化统一处理：**「超卖回升」= 进场持有，「超买回落」= 卖出空仓**；**绝不写「超买做空 / 超卖做多反手」**。

**F08 RSI 反转（14, 30/70）**
- 定义（Wilder RSI）：`Δ_t = C_t − C_{t−1}`；`Gain_t=max(Δ_t,0)`，`Loss_t=max(−Δ_t,0)`；`AG_t=RMA_14(Gain)`，`AL_t=RMA_14(Loss)`；`RS_t=AG_t/AL_t`；`RSI_t = 100 − 100/(1+RS_t)`（AL=0 → RSI=100；AG=0 → RSI=0）。
- 字段：`close`。
- 进场：`RSI_{t−1} ≤ 30` 且 `RSI_t > 30`（超卖回升上穿 30）。
- 出场：`RSI_{t−1} ≥ 70` 且 `RSI_t < 70`（超买回落下穿 70）。
- 纯多头：只做「超卖回升买 → 超买回落卖」；**不做「RSI>70 做空」**。来源 Wilder 1978（WebFetch 核验）+ StockCharts 译文（WebSearch 命中 70/30）。

**F09 KDJ（9, 3, 3）**
- 定义：`LLV_t=min(L_{t−8..t})`，`HHV_t=max(H_{t−8..t})`；`RSV_t=(C_t−LLV_t)/(HHV_t−LLV_t)×100`（分母 0 → RSV=50）；`K_t=(2/3)K_{t−1}+(1/3)RSV_t`（K_0=50）；`D_t=(2/3)D_{t−1}+(1/3)K_t`（D_0=50）；`J_t=3K_t−2D_t`（⚠️ **J 值变体未核实**，见 §2）。
- 字段：`high, low, close`。
- 进场：`K_{t−1} ≤ D_{t−1}` 且 `K_t > D_t` 且 `K_t < 20`（低位金叉）。
- 出场：`K_{t−1} ≥ D_{t−1}` 且 `K_t < D_t` 且 `K_t > 80`（高位死叉）。
- 纯多头：低位金叉持有、高位死叉空仓；**不做高位做空**。来源 George Lane Stochastic（经典文献）；**`J=3K−2D` 标「未核实·不编 URL」**，逐字定义按国内公开通用实现给出。

**F10 CCI（14, ±100）**
- 定义：`TP_t=(H_t+L_t+C_t)/3`；`MA_t=MA_14(TP)`；`MD_t=mean(|TP_{t−13..t} − MA_t|)`；`CCI_t=(TP_t−MA_t)/(0.015·MD_t)`（**0.015 为公开通用实现常数，本批未联网核验其文献出处，标「未核实」，不编 URL、不写论文结论**；MD=0 → CCI=0）。
- 字段：`high, low, close`。
- 进场：`CCI_{t−1} ≤ −100` 且 `CCI_t > −100`（上穿 −100）。
- 出场：`CCI_{t−1} ≥ 100` 且 `CCI_t < 100`（下穿 +100）。
- 纯多头：上穿 −100 持有、下穿 +100 空仓；**不做「+100 以上做空」**。来源 **未核实**（Donald Lambert 1980 为经典常识，本批 WebFetch/WebSearch 未取回正文 → 按派活单标「未核实」）。

**F11 威廉 %R（14, −80/−20）**
- 定义：`HHV_t=max(H_{t−13..t})`，`LLV_t=min(L_{t−13..t})`；`%R_t = (HHV_t − C_t)/(HHV_t − LLV_t) × (−100)`（取值 −100~0；分母 0 → −50）。
- 字段：`high, low, close`。
- 进场：`%R_{t−1} ≤ −80` 且 `%R_t > −80`（超卖回升上穿 −80）。
- 出场：`%R_{t−1} ≥ −20` 且 `%R_t < −20`（超买回落下穿 −20）。
- 纯多头：超卖回升持有、超买回落空仓；**不做超买做空**。来源 Larry Williams 1973（百度百科 WebSearch 命中）。

### §3.4 量价（2 个）+ 仅收录不单列回测项（3 项）

**F12 OBV 量价（OBV, MA30）**
- 定义：`OBV_0 = V_0`；`OBV_t = OBV_{t−1} + V_t` 若 `C_t > C_{t−1}`，`OBV_{t−1} − V_t` 若 `C_t < C_{t−1}`，否则 `OBV_{t−1}`；`OBVMA_t = MA_30(OBV)`。
- 字段：`close, volume`。
- 进场：`OBV_{t−1} ≤ OBVMA_{t−1}` 且 `OBV_t > OBVMA_t`（量能上穿）。
- 出场：`OBV_{t−1} ≥ OBVMA_{t−1}` 且 `OBV_t < OBVMA_t`（量能下穿）。
- 纯多头：量能上穿持有、下穿空仓。来源 Granville (1963)。**「成交量均线」已并入本因子与 F13，不另立。**

**F13 放量突破（量 MA20 × 1.5 + 前 20 日高）**
- 定义：`VMA20_t = MA_20(V)_t`；`UH_t = max(H_{t−20..t−1})`（`shift1` 前 20 日高，同 F05）；`MA20C_t = MA_20(C)_t`。
- 字段：`high, low, close, volume`。
- 进场：`V_t > 1.5 × VMA20_{t−1}` 且 `C_t > UH_t`（放量且收盘破前 20 日高）。
- 出场：`C_t < MA20C_t`（跌破 20 日均线）。
- 纯多头：放量突破持有、跌破均线空仓；**不做缩量做空**。来源 CSDN 海龟正文「成交量显著高于近期平均成交量（如过去 20 天均量）」（WebFetch 核验）+ F05 已核实的 `shift(1)` 通道。

**仅收录、不单列回测（3 项，如实标注）**
1. **换手率（Turnover Rate）**：公开定义 = `V_t / 流通股本 × 100%`；**计算需「流通股本」（非 OHLCV 字段）**，本机 `.day` 只有 OHLCV + 成交额 + 成交量，`base.dbf` 仅「当前基础信息」且无历史股本变迁序列（I-1 已核实）。→ **字段不满足，本批不纳入回测**，列 🔴 字段缺口；不脑补流通股本、不用成交量冒充换手率。
2. **格兰维尔法则（Granville 8 rules）**：经典文献（Joseph Granville），价格与 MA（常用 200 日）关系的 8 条买卖法则；纯多头可执行子集 = 法则①②（价格自下方上穿 MA / 回踩不破 MA → 买入；跌破 MA → 卖出）。**与 F01 双均线同族**，本批为避免同质重复 + 不铺参数网格 → **收录清单、不单列回测组**（来源与定义在此留痕，不算漏覆盖）。
3. **成交量均线 / 布林带宽 / ATR**：已分别并入 F12/F13、F06（BW 逐字给出）、F07，不另立因子（§1 第 6 条「统一参数、不寻优」）。
