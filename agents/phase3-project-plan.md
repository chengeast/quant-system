
## 1. 模块拆分（MVP 共 9 个模块）

### M1 数据层：Gate.io K 线接入与清洗 【负责人：数据工程师】
- 任务：REST `/spot/candlesticks` 分页拉取（1h≥730天 / 5m≥90天 / 1m≥30天）；(pair,ts) 去重；两腿 inner join 对齐；缺口/坏价分级标记；Parquet 落地 + 读接口。
- 验收标准：
  1. 指定币种对拉全指定区间，OHLCV 完整、时间戳连续（缺口报告=0 或已标注）
  2. 两腿对齐后 bar 数一致，零成交/坏价已打 `thin`/`bad_px` 标记
  3. 提供稳定读接口给下游（信号层）
- 依赖：无（起点）。风险：Gate.io 深历史 1m 拿不到 → 已限定 1m 仅 30 天。

### M2 币种对筛选 【负责人：数据工程师】
- 任务：按冻结阈值筛选——corr≥0.85、日成交≥$50M、价差≤5bp、EG(ADF p<0.05)+Johansen 双校验、半衰期 25–50 bars；输出评分表 Top3，PM 仲裁定 1 对。
- 验收标准：
  1. 评分表含：corr、日成交额、EG p、Johansen p、半衰期、综合排名
  2. 入选对的半衰期落在 [25,50] bars
  3. PM 签字确认最终币种对
- 依赖：M1。

### M3 信号层：价差 / z-score / 对冲比率 h 【负责人：后端架构师 + 代码审查员】
- 任务：价差 `A−h·B`；h=60bar 收益率 OLS，约束 h∈[0.5,2.0]、日变化率<10%、越界 INVALID；z-score 对原始价差算 μ/σ；σ=0/Var(B)=0 除零保护；t+1 跨 bar 防未来函数。
- 验收标准：
  1. 公式与 code_reviewer 清单 5 检查点逐条通过（spread=A−hB 非 A+hB；h 用收益率 OLS；σ 是价差标准差非残差；跨 bar 成交；回撤算净值）
  2. 异常输入（缺 K 线、零波动）不产生 NaN/崩溃信号
  3. 单元测试覆盖正常/边界/异常 3 类
- 依赖：M1。

### M4 决策层：进出规则 【负责人：后端架构师】
- 任务：按冻结参数——±3σ 进、0.5σ 出、单腿 2σ 止损、超时 max(3h,1.2H)；生成 OrderIntent（含仓位上限）；信号矛盾去重。
- 验收标准：
  1. 阈值边界判定正确（恰在 3σ/0.5σ 的开/关判定）
  2. OrderIntent 含 symbol/side/qty/limit_price/confidence/ttl
  3. 无仓位超上限的订单意图产生
- 依赖：M3。

### M5 风控层：订单闸门 + 紧急停止 【负责人：后端架构师 + 安全工程师】
- 任务：单笔/总敞口上限拦截；5min 拒单率>20% 或权益骤降→触发紧急停止（撤单+平仓+暂停 24h）；拒单记日志；APIKEY 只读校验。
- 验收标准：
  1. 超敞口/超额订单被拦截且记录拒单原因
  2. 紧急停止开关可触发并正确下发执行层；恢复需二次确认
  3. 密钥仅只读权限，访问留痕
- 依赖：M4。

### M6 执行层：模拟撮合 + 对账 【负责人：后端架构师】
- 任务：PaperBroker 模拟成交（计入 taker 0.1% + 滑点 3–5bp/边）；Reconciler 定期对账；对账偏差>0.5% 置 DRIFT。
- 验收标准：
  1. 成交回报含 fill_qty/price/fee/slippage/latency
  2. 本地持仓 vs 远端对账一致（偏差在阈值内）
  3. 滑点假设≥3–5bp，不假设 0 滑点
- 依赖：M5。

### M7 监控层：指标 + 告警 【负责人：性能/可观测性工程师】
- 任务：各层事件订阅（信号/订单/拒单/对账/缺口）；延迟/数据断流/价差发散告警；Webhook 通知；回测耗时基准。
- 验收标准：
  1. 数据断流、价差发散、对账 DRIFT 三类告警可触发
  2. 通知通道失败有重试
  3. 非关键路径（不阻塞核心链路）
- 依赖：M1–M6（并行收尾）。

### M8 回测引擎 + 报告 【负责人：测试工程师 + 数据工程师】
- 任务：跑端到端回测（扣费+滑点，t+1 成交）；产出"四件套+成本可执行性"指标；含 2024-09 极端段；固定种子+固定数据 golden value 快照。
- 验收标准（对应冻结门槛）：
  1. 净收益>0 且跑赢 BTC 单边
  2. 最大回撤≤10%、夏普≥2.0、Calmar≥1.5
  3. 滑点≥3–5bp、每笔成本≤毛利35%、最长连亏≤5 笔
  4. 含 2024-09 极端段不亏
- 依赖：M1–M6。

### M9 参数校验 CI + 前端看板 【负责人：运维 + 前端工程师】
- 任务：`verify_params.py` 接入 CI（回测前强制校验参数一致性）；看板展示 K线+价差+z曲线+持仓+净值+告警。
- 验收标准：
  1. 参数被改未留痕时 CI 阻断回测
  2. 看板正确渲染核心指标
  3. 非关键路径
- 依赖：M8 后。
