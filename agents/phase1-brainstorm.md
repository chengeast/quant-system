# 阶段 1 · 头脑风暴纪要（目标 / 规则 / 约束）

> 产出角色：项目经理（主）+ 全体 10 角色会签
> 状态：待用户确认。确认后冻结为本项目的最高裁判基准。

## 1. 目标（Goal）
以 Gate.io 历史 K 线数据，完成**统计套利（配对交易 / 均值回归）**的端到端全链路 MVP，
交付一份**可复现、可验证**的回测报告。MVP 阶段只做**模拟/回测**，不做实盘。

## 2. 规则（Rules）—— 写入文档，签字确认
| 编号 | 规则 | 裁决依据 |
|----|------|---------|
| R1 | 币种对**不锁定**：由数据工程师用相关性+协整筛选，输出评分表，PM 仲裁选 1 对 | 数据筛选评分 |
| R2 | 数据源：Gate.io K 线 OHLCV；主尺度 1h（参数标定），默认回测 5m，1m 仅做滑点 | 数据工程师结论 |
| R3 | 6 层每层先定**接口契约**（入参/出参/异常语义），阶段 2 详化 | 后端架构师结论 |
| R4 | 验收"四件套"：回测必须给**夏普 / 最大回撤 / 胜率 / 分时段表现**，并扣手续费+滑点 | 测试工程师结论 |
| R5 | 信号 t 出、t+1 成交，杜绝未来函数 | 代码审查员红线 |
| R6 | 价差 σ=0、Var(B)=0 等除零场景必须显式保护并跳信号 | 代码审查员红线 |

## 3. 约束（Constraints）—— 硬边界，不可协商
- **C1** 密钥/APIKEY 走 `.env` + `.gitignore`，绝不入仓库；MVP 只开**只读**权限，关下单/提现。
- **C2** 只做模拟/回测，实盘开关默认关闭，且与模拟物理隔离。
- **C3** 所有结论必须带数据支撑，不允许"我觉得"。
- **C4** 单交易所（Gate.io）起步，**不做跨所套利**（价差薄、拼不过高频）。
- **C5** 不做 A 股（历史数据用户另供、量大，留后期）。
- **C6（用户新增）** 项目重要参数分级管理：
  - **敏感凭据**（APIKEY/SECRET/实盘密钥）：加密/走系统 KeyVault，绝不落盘明文，绝不进 Git。
  - **策略参数**（±3σ、半衰期 25–50 bars、夏普≥2.0 等）：落 `config/strategy_params.yaml`，带 **SHA256 校验和 + audit 留痕**，改动须走 `verify_params.py --update` 记录操作人/前后值/理由；回测前强制校验参数一致性。
  - **讨论纪要/架构文档**：不加密，保持可读可 review 可追溯（Git 即天然留痕）。
  - 实盘开关：独立密钥 + 二次确认 + 人工审批 + 与数据密钥隔离，默认关闭。

## 4. MVP 边界（明确不含）
- 不含：做市、订单流、波动率模型（这三者仅在信号层留占位，决策层只实跑统计套利）
- 不含：实盘、跨所、A 股、A 股实时爬虫
