## §3 阶段二验收（回测层 · 后端架构师纪律）

**新增** `backtest/a_share_portfolio_factors.py`（保留 `backtest/` 下全部旧脚本不动、不改 `src/`）；信号层**只读复用 I-3 的 `FACTORS` / `compute_target()` 逐字不改**，15 因子统一参数、不铺网格、不寻优；**成交层重写为组合引擎**。

### 3.1 组合资金模型（严禁逐笔盈亏无条件累加）

- 初始资金主档 **100 万元**（工程师设定并写明理由：A 股 100 股整手下按 `MAX_POSITIONS=10` 等权分仓每票 10 万元，可覆盖多数股价且留足分仓空间）。
- **可用现金 `cash` + 持仓市值 `mv` + 逐日盯市权益曲线 `equity[g] = cash + Σ(持仓股数 × 当日盯市 close)`**；停牌 / 无 bar 日用最近有效 close 前值填充。**严禁把逐笔盈亏无条件累加到一条固定曲线**（I-3/I-4 被点名缺陷）。
- **买入前现金校验**：`成交额 + 买入佣金 ≤ 可用现金` 才成交；成交后现金实时扣减、**同一笔资金不得重复占用**；买不起 1 手（100 股）则跳过并如实计数。
- **100 股整数倍**：`shares = floor(budget / open / 100) × 100`，`成交额 = shares × t+1 open 真实股价`（不再是固定 1000 元名义）。

### 3.2 选股 / 分仓（老板核心诉求）

- 每交易日**扫描全池 5687 只**，收集该因子进场信号（`target 0→1`）命中的候选。
- **选股排序 `SORT_RULE = signal_day_amount_desc_then_symbol_asc`**：候选数 > 可用仓位时按**信号日成交额 `amount` 降序（流动性优先、无未来函数）**取前 N，同额按**代码升序** tie-break。进场事件为布尔跳变、无连续「信号强度」可定义，**不臆造强度分数**；规则写入常量并落 json 留痕，**不隐式随机、不脑补**。
- **`MAX_POSITIONS`** 主档 10、敏感性 5/10/20；**单票仓位上限 = 等权 1/N**（`per_position_budget = 初始资金 / MAX_POSITIONS`），按初始资金固定分仓。

### 3.3 卖出 / T+1 / 末尾强平

持仓中个股**只有达到该因子出场信号（`target 1→0`）才卖出**；**t 收盘出信号 → t+1 open 成交**；`MIN_HOLD_BARS=1` 逐笔 `exit_date>entry_date`、`exit_bar>entry_bar`；**不用日内 OHLC 臆造同日反向成交**；末尾未平仓 `end_force_close` 按最后一根 close 强平、如实计入（主档 53 笔）；纯多头，禁一切空头暴露。

### 3.4 敏感性 / 基准 / 逐因子申报

- **敏感性对照（非寻优）**：`MAX_POSITIONS ∈ {5,10,20}` × `初始资金 ∈ {50万,100万,500万}` = **9 档 × 15 因子 = 135 组**，`is_optimization=false`，明确标注「参数敏感性对照，非参数寻优、不挑最优」。
- **基准**：全市场个股每日等权买入持有（同初始资金 100 万）+ `sh000001` / `sz399001` / `sh000300` 买入持有 → 累计 / 年化 / 回撤 / 夏普 + 逐因子跑赢 / 跑输。
- **逐因子申报**：成交数、持仓峰值 / 均值、平均持仓天数、现金利用率、gross / cost（元）/ net、年化、回撤、Calmar、夏普(参考)、连亏、胜率、4 条门槛逐条、笔数≥30、`t1_violations`、5 元最低佣金触发率；`summary` 含 `n_stocks_in_pool` / `n_stocks_actually_traded` / `n_bars` / 两个达标数 / `extreme_gate` / 数据指纹 / 参数指纹 / 假设标签 / `adjusted=false` / 实际覆盖声明。
- **双成本口径**：primary（主口径）与 conservative（加回过户 + 滑点，**同成交时序、仅成本金额不同**），保守对照如实标注、不写成独立重跑结论；累计收益 ≤ −100% 时年化标「不可定义」、不用 0 占位。
