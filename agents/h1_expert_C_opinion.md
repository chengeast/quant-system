## 1. 任务一 · 公开来源核实（C 视角：逐类算「成本 / 费率 / 延迟 / 执行」账）

**〔账目 1〕AQR TSMOM / CTA 趋势 / 价值·动量·Carry 跨资产因子**
- 来源：Moskowitz/Ooi/Pedersen 2012 *JFE* + AQR 官方 `Time-Series-Momentum-Factors-Monthly`（✅ 重试可达）、Asness 2013 *JoF* 68(3):929-985（✅）、Koijen 2018 *JFE* 127(2) Carry（✅）；**AQR Carry 官方数据集 = 未核实**。
- 买卖条件逐字：「12-month…1-month holding period」「58 underlying liquid instruments」「based on a 12-month time series momentum strategy」。
- **C 的成本账**：机构版 = **月度换手 + 期货 + 机构费率档 + 波动率缩放**。低频换手是它能活的关键：一个月调一次仓，roundtrip 成本被 1 个月位移摊薄。本机若把它降频到 1d/4h 现货，`phase6 §0` 逐字已证「降换手：总毛利与总成本同比减少，比值不变」——**降频不改善成本/毛利比**，只改变绝对量。机构靠的是「月度单笔位移 >> 28bp」，不是靠省手续费。

**〔账目 2〕市场中性统计套利 / 配对（GGR 2006 *RFS* ✅）**
- 买卖条件逐字：「matched into pairs with minimum distance between normalized historical prices」；各机构逐字买卖条件 = **未核实（黑箱）**。

**〔账目 3〕期现 / funding carry（delta-neutral）**
- 来源：百度百科「资金费率」✅、php/CSDN ✅、Springer 综述 2022 ✅；**百家号 2025-03 具体篇 = 未核实**。逐字「费率为正时，多头持仓者向空头支付费用」（8h）。

**〔账目 4〕跨所 / 三角套利（CEX-DEX）**

## 4. 参数建议（soul L17 要求本人必须给，成本/可执行性口径）

1. **成本占收益比阈值**：`cost_ok` 按 **成本/毛利 ≤0.35** 复算口径（不设 40% 中间档），沿用 G-2/G-3 的 C 加严口径；G-4-② 老板 A 方案曾把 config 的 `max_cost_as_pct_of_gross` 改 0.50，但那是老板新指令的历史留痕，**H-1 讨论基线按冻结 ≤0.35、本批不改 config**。
2. **滑点假设**：现货 taker 4bp/边（保守上界，`phase7` 实测 $500 量级仅 0.02/0.56bp）、maker 0.5bp/边（假设值、盘上无实测）；**滑点清零只降 14%**，不作为翻盘手段。
3. **时延 / 抢跑**：含 1~3s 成交时延（0.1bp 假设值、盘上无实测）+ 0.5x 毛利抢跑折扣，沿用 G-3。
4. **最小半衰期 / 成本关系**：本人不报一个「可行的最小半衰期」—— `phase6 §0` 已证拉长半衰期 / 降换手不改变成本/毛利比，只摊薄绝对量；`phase6 §1` 门槛要求单笔毛利 ≥80bp（成本/毛利 ≤0.35 对应 28bp×…），而本机 1h 单笔毛利 10.6bp，**任何半衰期都补不上 5.10× 缺口**。如实写「无可行半衰期参数，须改成本分子或单笔位移」，不粉饰。
5. **费率档分报**：现货腿 taker=maker=0.1%/边、合约腿 taker=0.05% maker=0.02%/边，**双腿分报不混用**；`phase7`「taker 0.1% 占 71% / roundtrip 28bp」**仅适用现货均值回归主线**，不得写成全局根因（老板 11-12 澄清、11-15 再确认，dispatch_log「九」）。
