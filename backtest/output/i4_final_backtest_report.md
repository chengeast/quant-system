## §3 资金模型说明与 I-3 缺陷限制

**主口径 / 保守 / I-3 旧口径**沿用 I-3 的**简化权益曲线**：把 12 个标的的全部交易净盈亏按 `exit_date` 累加到同一条 `BASE_EQUITY = 10000` 曲线；每笔按 `NOTIONAL = 1000` 元名义成交，**无资金占用 / 并行持仓检查**（12 标的同时持仓理论需 12000 元 > 本金）。I-3 秘书 §十四 核出的**资金口径缺陷仍在**：`total_return / max_dd / sharpe / calmar` 均建立在该简化曲线上，**分母不是真实占用资金**，结果带「该口径下」限制，不能当最终判定。

**附加对照口径 · 真实资金模型（秘书建议、非老板指定；单列一节、不覆盖主口径）**：
- 名义按 **1 万元量级**、按 **100 股整数倍取整**（`LOT = 100`）；
- **逐笔资金占用检查**：开仓需 `买入成交额 + 买入佣金 ≤ 可用现金`，且活跃持仓数 < **并行持仓上限**；不满足则跳过并如实计数；
- **权益曲线** = 现金 + 持仓市值（按当日 open），**分母 = 真实投入资金** `REAL_INITIAL_CAPITAL`；
- 费率结构与主口径相同（佣金 `max(成交额×0.0005,5)`、印花税 0 / 过户 0 / 滑点 0）；
- 参数 `目标名义 1 万元 / 100 股取整 / 初始资金 500 万 / 并行上限 12` 全部为**对照口径假设、非老板指定、盘上无实测**，如实标注。

**真实资金模型逐笔资金占用拒绝（如实申报，主池 15 因子合计）**：15 因子候选 43,402 笔中，8 个因子出现资金不足拒绝（F08 72 / F10 207 / F11 339 / F14 5 / F15 315 笔等，主池合计 **938 笔**被拒），实际成交 **42,464 笔**；**并行上限未触发拒绝（0 笔）**。被拒笔数逐因子落盘，未静默吞。
